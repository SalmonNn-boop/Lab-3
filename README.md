Технологии:
HTML, CSS, Vanilla JS

Инструкция:
1. Перед запуском все файлы (index.html, app.js и styles.css) необходимо разместить в одной папке.
2. Далее двойным кликом открыть index.html.
3. В карточке есть два поля. Левое поле используется для вывода публикаций, правое - для создания публикации. Чтобы вывести первые 5 публикаций, необходимо нажать на кнопку "Загрузить публикации". Публикации появятся в нижней части левой карточки. 
4. Чтобы создать публикацию, необходимо ввести заголовок и описание. Затем нажать на кнопку "Создать публикацию". Если публикация успешно создалась, она высветится в левом поле.

Обработка ошибок:
1. Если не удается установить соединение с API, вверху карточки выводится соответствующая ошибка.
2. Если поля "заголовок" и "описание" пустые, также появляются уведомления о том, что поля необходимо заполнить.
